# BeSpoke guided builder

Mode: **Operate**. Scope: the guided builder in this directory only. This is an extension of the existing SPOKES visual identity, with no replacement-world workshop. Root `PRODUCT.md` concerns the dashboard; it does not determine this builder's composition.

Audience: curriculum teams who may not know design terminology. Job: choose and compare a lesson's reusable visual model, save the agreed model, and request review. The sample artifact makes each choice concrete before a lesson is built.

**THESIS:** Novice decisions sit beside a cumulative artifact preview. The controls expose one manageable group of choices while preserving the entire design.

**OWN-WORLD:** Existing SPOKES navy, blue, white, bridge logo, and Outfit UI. The preview uses the 11 approved role colors and 12 independently selectable existing lesson fonts. Its chosen palette and type do not repaint chrome.

**STORY:** Start with guided controls or an editable preset; refine colors, type, and slide styles; compare the cumulative sample; save and review the reusable model. Saving does not authorize lesson construction.

**FIRST VIEWPORT:** Desktop presents step navigation and current controls beside a large slide preview with comparison below. The header retains save, open, and review actions. Mobile offers Design and Preview surfaces with horizontal step navigation.

**FORM:** Operate extension with pinned identity. The memorable interaction is a small choice producing an immediate, cumulative change in the artifact while the controls remain stable.

Constraints: direct palette roles, independent heading/body fonts, shared rendering model, local font assets, recoverable drafts, explicit readability repair, labeled sample content, and advisory comparison. Released lessons and the dashboard are outside this surface's design scope.

Recorded from the implemented sources after the parent task's finish review. This documentation pass made no UI changes and did not run a browser review. No unresolved visual-world decision was identified in the documentation scope.
