Adult education instructor teams

Your next team meeting with Bespoke

Use Bespoke to agree on how your lesson will look. Write the lesson together in Word. Your shared OneDrive folder keeps the team’s files between meetings. You do not need to know code or use GitHub.

Set up once

Ask Britt or your team lead for the Bespoke website link and your lesson’s shared folder link. Pin both in your Teams channel. Check that everyone can open the folder. Choose one spokesperson to operate Bespoke and save the team file.

Save one copy of the Word lesson form in that folder. Give it a clear name such as Goal Setting Team Lesson.docx. Everyone edits that same document in Word through Teams or OneDrive. Put source documents, pictures and videos alongside it. Keep earlier versions when you replace a file.

At the start of each call

  1. The spokesperson finds the newest Bespoke team file in the shared folder and downloads it. The filename ends in selection.json. Do not double-click it or try to edit its contents.
  2. Open the Bespoke website in your browser and choose Open team file. Select the downloaded file. Check the lesson name and the team’s previous choices. For your first meeting, choose Next and enter your lesson and spokesperson instead.
  3. Share the browser window in your Teams call. Choose a starter theme and discuss the preview together. The spokesperson changes the options as the team decides. Teammates can keep notes in your shared Word document.

Before you end the call

  1. Choose Save team file in Bespoke. This downloads a new file with the lesson name and time in its filename.
  2. Move or upload the file from Downloads into your shared lesson folder. Wait until OneDrive finishes syncing. Saving in Bespoke does not automatically upload it.
  3. In Teams, record which file is the latest and what the team decided. At the next meeting, open that file. Let one spokesperson save each revision so you do not accidentally make competing copies.

When the team is ready for review

In Bespoke, go to Review & submit and choose Prepare for Britt’s review. Move the downloaded REVIEW file into the shared folder. Tell Britt in Teams that the file and your Word lesson document are ready. The website does not send a message or start building the lesson.

Britt checks the package and approves the build. Your team then reviews the finished lesson, including the wording, activities, resources and design. A preview in Bespoke is a design sample, not a finished lesson.

The two files have different jobs. The Word document holds your complete lesson and research. The Bespoke team file holds design choices and sample text. Both are needed before a lesson can be built.

If something goes wrong

  • Your browser draft is missing: choose Open team file and use the latest file from the shared folder.
  • You opened the wrong file: choose Recover previous draft, or open the correct team file.
  • Another tab changed the draft: save a team file to keep this tab’s work, close extra Bespoke tabs, then reload and open the version your team agrees to use.
  • A file will not open: check that it is the small Bespoke selection.json file. Keep the file and ask Britt to check it. Do not change its text.
  • You need an older cloud file: ask the lead to use OneDrive Version history. Keep the current copy before replacing it.

Optional view links

A view link shows one moment in the design. It will not show later changes. It also contains the sample text and team contact details, so share it only with intended reviewers. The optional edit code is a convenience lock; it is not a private account. The team file is the simplest way to continue next time.

Target for this phase: March 2027, with room to adjust for review and testing. Each team’s lesson is released when it is ready, not just because a date arrives.
