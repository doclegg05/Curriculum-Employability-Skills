Adult education instructor teams

Your next team meeting with Bespoke

Use Bespoke to choose how your lesson will look: its colors, fonts, backgrounds, title, section dividers and cards. Discuss the preview together during a Teams call, then save your visual choices in the shared OneDrive folder. You do not need to write a lesson, know code or use GitHub to use Bespoke.

Open Bespoke

Set up once

Ask Britt or your team lead for the Bespoke website link and your lesson’s shared folder link. Pin both in your Teams channel. Check that everyone can open the folder. Choose one spokesperson to operate Bespoke and save the team file.

The shared folder holds the saved Bespoke design files. Keep earlier versions so the team can return to an earlier look if needed. The spokesperson saves one agreed version after each meeting.

At the start of each call

  1. The spokesperson finds the newest Bespoke team file in the shared folder and downloads it. The filename ends in selection.json. Do not double-click it or try to edit its contents.
  2. Open the Bespoke website in your browser and choose Open team file. Select the downloaded file. Check the lesson name and the team’s previous choices. For your first meeting, choose Next and enter your lesson and spokesperson instead.
  3. Share the browser window in your Teams call. The spokesperson changes the options as the team decides; everyone watches the same preview.

Choose the look together

  1. Theme preset: pick the closest starting look. You can keep it as it is, or adjust the options below.
  2. Color lead and background: try the main color, sidebar and background texture. The choices come from the approved SPOKES library.
  3. Title and dividers: compare the opening slide and section-divider layouts. Use the Title and Divider preview tabs to see them.
  4. Cards and fonts: compare card shapes and typefaces. Use the Cards preview tab. Leave Vary by chapter off for one consistent card style, or turn it on to compare different chapter styles.
  5. Try sample text: optionally change a title or a few sample lines to see how they fit. The supplied text is enough to choose a look. Nothing here requires a completed lesson.
  6. Review: check the summary together and agree which look to keep. On a small screen, use Design and Preview to switch between controls and the sample.

Before you end the call

  1. Choose Save team file in Bespoke. This downloads a new file with the lesson name and time in its filename.
  2. Move or upload the file from Downloads into your shared lesson folder. Wait until OneDrive finishes syncing. Saving in Bespoke does not automatically upload it.
  3. In Teams, record which file is the latest and what the team decided. At the next meeting, open that file. Let one spokesperson save each revision so you do not accidentally make competing copies.

When the team is ready for review

In Bespoke, go to Review & submit and choose Prepare for Britt’s review. Move the downloaded REVIEW file into the shared folder. Tell Britt in Teams which design file is ready for review. The website does not send a message or start building the lesson.

Britt reviews the selected look. Those approved choices guide the later lesson build, and your team checks that the finished lesson displays them correctly. A preview in Bespoke is a design sample.

Your design file is all you need for this workflow. It saves the visual choices and any optional preview text. Lesson writing, research and teaching materials follow their own process.

If something goes wrong

  • Your browser draft is missing: choose Open team file and use the latest file from the shared folder.
  • You opened the wrong file: choose Recover previous draft, or open the correct team file.
  • Another tab changed the draft: save a team file to keep this tab’s work, close extra Bespoke tabs, then reload and open the version your team agrees to use.
  • A file will not open: check that it is the small Bespoke selection.json file. Keep the file and ask Britt to check it. Do not change its text.
  • You need an older cloud file: ask the lead to use OneDrive Version history. Keep the current copy before replacing it.

Optional view links

A view link shows one moment in the design. It will not show later changes. It also contains the sample text and team contact details, so share it only with intended reviewers. The optional edit code is a convenience lock; it is not a private account. The team file is the simplest way to continue next time.

Save the agreed design after each meeting. Open that saved file when you return.
