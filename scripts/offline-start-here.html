Open the lessons

Opened this from inside a zip file?

The lessons won't open from there. Close this page, right-click the zip file and choose Extract All, then open START HERE from the folder it makes. On a Mac, double-click the zip instead.

Before class

  • Keep this folder together. Copy the whole folder, not single files.
  • Plug the flash drive into the computer that's connected to the projector. A projector can't run the lessons on its own.
  • Open the lessons in Chrome or Edge. Safari works on a Mac.
  • If the computer won't open files from the flash drive, copy this folder to the computer's desktop and open it from there.

Good to know

  • Every video has captions. Turn them on from the video's controls.
  • The Jeopardy game in Controlling Anger is a website, so it needs the internet. Everything else works offline.
  • This copy won't update itself. When the lessons change, download a new copy and replace this folder.
