Section 2: Theme Matrix — Layered Theme System

Each lesson gets an overall theme identity PLUS chapter-level variation within it. Think of it like a song: the key signature stays the same, but verses and choruses have different arrangements.

Two Layers of Theming

LAYER 1 — LESSON IDENTITY
Stays consistent across the whole lesson
  • Color lead — which brand color dominates
  • Sidebar color — --dark or --royal
  • Font pairing — heading + body fonts
  • Title slide design — the opening impression
  • Background texture — the base pattern underneath
LAYER 2 — CHAPTER VARIATION
Changes between chapters to keep it fresh
  • Card style — rotates across chapters (2-3 per lesson)
  • Section divider style — varies per chapter
  • Component mix — different component types per chapter
  • Accent shifts — secondary color emphasis can shift

The Rule: Coherent but Not Monotonous

  • Layer 1 (lesson identity) holds constant — you always know you're in the "Controlling Anger" lesson
  • Layer 2 (chapter variation) rotates — each chapter transition brings visual refresh
  • Card styles rotate across 2-3 options per lesson (← markers in example above)
  • Section dividers use different styles per chapter — no two adjacent chapters use the same divider
  • Component types vary by chapter (no two adjacent chapters use the same component sequence)

Chapter Variation Rules

  • Card styles: Assign 2-3 from the 8 options per lesson. Rotate by chapter. No adjacent chapters use the same card style.
  • Section dividers: Assign 3-4 from the 5 options per lesson. No adjacent chapters use the same divider.
  • Components: No two adjacent chapters should lead with the same component type (e.g., no cards-grid → cards-grid).
  • Accent shifts: Secondary color emphasis can subtly shift between chapters (e.g., P1 leans gold, P2 leans green) while the lead color stays dominant.
