How Card Styles Apply

Each card style affects all components in a lesson — cards-grid, takeaway numbers, smart-stack letters, matrix cells, areas-grid, and flip cards all shift to match. The theme-override CSS handles this by redefining border-radius, box-shadow, border placement, and background patterns for all component classes.
